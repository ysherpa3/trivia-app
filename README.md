# Trivia Challenge

Next.js 16 trivia quiz app using the [Open Trivia Database API](https://opentdb.com). Configure question count, category, and difficulty; play through questions with live score tracking; review answers at the end.

## Features

- Multiple choice questions with configurable category, difficulty, and count
- Answer feedback before advancing to the next question
- End the quiz early at any point
- Score summary with per-question breakdown at the end
- Questions fetched server-side to avoid browser rate limits

## Stack

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS v4

## Getting Started

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).
